# KeepShop

[English](README.md) · **Русский**

KeepShop — списки покупок для Android (и браузера) с базой товаров, оценкой цен, рецептами, ИИ-помощником и кошельком дисконтных карт. Интерфейс на русском, ссылки поиска товаров настроены на магазины Польши (Biedronka, Lidl, Żabka, Auchan, Carrefour, Kaufland…).

Данные хранятся на устройстве, пока вы не включите **семейный доступ**. Тогда они хранятся в общем семейном пространстве в Firebase, и читать их могут только участники семьи. Запросы к ИИ, которые вы запускаете сами, идут в Google Gemini с вашим собственным ключом.

## Возможности

### Списки покупок
- **«Недавние»** (первая вкладка) — главный, текущий список покупок. Его можно показывать компактными строками или подробными карточками.
  - Тап по строке отмечает товар «взял». Отмеченный товар остаётся на своём месте.
  - Удержание и протягивание меняет порядок; обычный свайп при этом прокручивает список.
  - Долгое удержание или тап по количеству открывает редактирование.
- **«Списки»** — сколько угодно дополнительных списков, у каждого свой цвет, сортировка, участники и вид.
- **«Отменить»** для любых удалений и массовых изменений: кнопкой в уведомлении или Ctrl+Z.
- **Свайп** влево-вправо переключает разделы. Эффект перехода выбирается: сдвиг, 3D-поворот, карточки или без анимации.

### Добавление товаров
- **Окно подбора** с четырьмя вкладками: Популярное, Каталог (отделы магазина и фильтры: вегетарианское, веганское, кето, без глютена, много белка, заморозка), Недавние и **Из блюда**.
- **Из блюда:** вводите название блюда и получаете список продуктов.
  - 25 встроенных рецептов работают без интернета.
  - Любое другое блюдо разбирает Gemini AI.
  - Количества пересчитываются под число порций.
- **Подсказки «С этим часто берут»** появляются после добавления товара, например: спагетти → пармезан, фарш, чеснок. Источников четыре:
  - ваша история покупок (что куплено в один день);
  - ваши ручные связи;
  - рецепты;
  - типичные пары.

### База товаров
- Единый редактируемый справочник, не зависящий от списков. В комплекте ~440 товаров с уже размеченными отделами, метками и ориентировочными ценами (`src/data/products.json`).
- Можно добавлять, изменять и удалять товары, связывать похожие и фильтровать по отделам. ИИ умеет разложить «Прочее» по отделам.
- Каждый новый товар, добавленный в список, сам попадает в базу.

### Цены
- Ориентировочные цены (с пометкой **≈**) берутся из четырёх источников:
  - ваша история цен;
  - база товаров;
  - встроенный справочник цен, который понимает формы слов и синонимы;
  - Gemini AI для всего остального.
- История цен с графиком по каждому товару.
- **Важно:** сравнение «📍 Цены» по магазинам на карте — **имитация**. Открытого API цен у сетей нет, поэтому результаты ориентировочные и помечены ≈.

### Акции из газеток
- «🏷 Акции» в «Недавних» (или меню ⋮) находит действующие акции на товары, которые ещё нужно купить. Blix.pl находит страницы газеток выбранных сетей (Biedronka, Lidl, Kaufland, Auchan и другие), где есть товар, а Gemini читает со страниц цену, старую цену, скидку, условия и сроки.
- У товара с акцией появляется метка «🏷 −34%», у каждой акции — ссылка на страницу газетки. По желанию проверка раз в день при запуске: плашка или уведомление Android о новых акциях.
- Работает с бесплатным ключом Gemini.

### Навести порядок: названия и цены
- Меню ⋮ → «🧹 Навести порядок» проверяет все товары в списках, истории, избранном и базе: расшифровывает сокращения из чеков (`PiwTyskie0,5lPus` → «Пиво Tyskie 0,5 л, банка»), исправляет опечатки и разговорные слова, сохраняет ваши уточнения в скобках.
- Цены обновляются по последним настоящим покупкам; товары совсем без цены получают оценку (≈).
- Сначала всё показывается в предпросмотре с галочками; перед применением сохраняется копия базы, есть «Отменить». Старые написания запоминаются, и новые чеки сразу получают нормальные названия.
- Товары, добавленные без цены, получают её автоматически в фоне (история, база товаров, справочник, затем оценка Gemini).

### Дисконтные карты (по образцу Catima)
- Карту можно добавить тремя способами: **сканировать камерой**, распознать штрихкод с **фото** или ввести вручную.
- 13 форматов штрихкодов: QR, EAN-13/8, UPC-A/E, Code 128/39/93, ITF, PDF417, Aztec, Data Matrix, Codabar.
- Для известных сетей фирменный цвет подставляется сам. Можно указать баланс, срок действия, заметку, фото обеих сторон и отметить избранные.
- Список карт показывается строками или цветными плитками. Штрихкод по тапу открывается во весь экран.
- **Импорт из Catima:** ZIP-экспорт вместе с фото или `catima.csv`. Подойдёт и простой CSV с колонками «магазин» и «номер». **Экспорт для Catima** делает ZIP.

### Семейный доступ
- Одно общее пространство на всю семью: списки, «Недавние», база товаров, история покупок, цены и дисконтные карты одинаковые на всех телефонах.
- Изменения доходят до других телефонов примерно за секунду. Без интернета приложение работает, а правки синхронизируются сами, когда связь вернётся.
- Чтобы пригласить человека, нажмите «Пригласить в семью» и отправьте код из 8 символов (действует 7 дней). Второй человек открывает меню ⋮ → «Семейный доступ» и вводит код. Его прежние данные сначала сохраняются в резервную копию, затем заменяются данными семьи.
- Аккаунт не обязателен: телефоны входят анонимно. Читать и менять данные семьи могут только её участники, это обеспечивают правила доступа Firestore (`firestore.rules`).
- **Вход через Google** (по желанию) привязывает ваш Google-аккаунт к участию в семье. После переустановки приложения или на новом телефоне достаточно войти через Google, и семья подключится сама, новый код не нужен. На Android используется системное окно выбора аккаунта.
- Владелец видит всех участников и может удалить кого-то из семьи. Любой участник может выйти, его данные остаются на телефоне.
- **Кто что взял:** у отмеченного товара видно, кто его взял («✓ Аня»), у новых товаров видно, кто их добавил.
- **📜 Журнал семьи** (🔔 в шапке): общая лента действий участников: добавлено, взято, снова нужно, убрано, изменено, списки, карты, приглашения, вступление и выход. Массовые действия сворачиваются в одну запись, перестановки в журнал не попадают.
- **Уведомления:** плашка о действиях других участников, счётчик непрочитанного на 🔔, сводка «Пока вас не было» при открытии приложения и уведомление Android, пока приложение работает в фоне. Их можно выключить в журнале. Когда приложение полностью закрыто, уведомления не приходят, события видны в сводке при следующем открытии.

### Резервные копии
- После каждого изменения база дублируется во внутреннюю память телефона и восстанавливается сама, если данные WebView пропадут.
- Автоматические копии делаются раз в день или неделю в `Documents/KeepShop/`. Эта папка видна в файловом менеджере и сохраняется даже после удаления приложения. Хранятся 10 последних копий.
- Копию можно восстановить (с отменой) или отправить на Google Drive, в Telegram, на почту. Импорт и экспорт используют тот же формат файла.

### Прочее
- Импорт из Google Keep, ИИ-распознавание чеков, статистика, автоперевод названий для поиска в местных магазинах, тёмная тема, поддержка кнопки «Назад» на Android.

## Установка

Скачайте APK из [Releases](../../releases). На телефоне разрешите установку из этого источника и откройте файл.

Нужен Android 6.0+ (API 23+). Приложение само проверяет новые версии на GitHub (меню ⋮ → «⬆️ Проверить обновления»), скачивает APK и открывает установщик Android; данные сохраняются. В первый раз Android попросит разрешить установку из KeepShop. Для функций ИИ укажите бесплатный ключ Gemini с [aistudio.google.com/apikey](https://aistudio.google.com/apikey) в меню ⋮ → «🔑 Ключ Gemini AI». Ключ хранится только на устройстве.

## Настройка семейного доступа (для своей сборки)

Семейный доступ работает через Firebase. Настройки подключения лежат в `src/firebase-config.ts`, и готовый APK уже подключён к проекту KeepShop. Чтобы использовать свой проект Firebase:

1. В [консоли Firebase](https://console.firebase.google.com) создайте проект и добавьте **Web-приложение**. Скопируйте его `firebaseConfig` в `src/firebase-config.ts`.
2. В **Authentication → Sign-in method** включите **Anonymous**.
3. Для входа через Google включите **Google** в Sign-in method. Добавьте Android-приложение `ai.keepshop.app` с отпечатками SHA-1 своих ключей подписи (отладочного и релизного), скачайте `google-services.json` и положите его в `android/app/` (файл не коммитится).
4. Создайте **Firestore Database** (рабочий режим). Затем опубликуйте правила из `firestore.rules` (вкладка Rules) или выполните `npx firebase-tools deploy --only firestore:rules`.

Чтобы проверить локально на двух «телефонах», запустите `npx firebase-tools emulators:start --only auth,firestore` и откройте приложение с `?emu=1`.

## Сборка из исходников

Нужны Node.js 20+, JDK 21 и Android SDK (platform 35, build-tools 35).

```bash
npm install
npm run dev            # сервер разработки http://localhost:5173
npm run build          # проверка типов + сборка в www/
npm run build:single   # всё приложение одним HTML-файлом: dist-single/keepshop_ai.html
npm run sync           # сборка + копирование в Android-проект (Capacitor)
```

Сборка APK для Android:

```bash
cd android
./gradlew assembleDebug      # android/app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease    # подписанный, если есть android/keystore.properties
```

Для подписанного релиза скопируйте `android/keystore.properties.example` в `android/keystore.properties` и укажите свой ключ. Ключ и пароли никогда не коммитьте.

## Структура проекта

| Путь | Что внутри |
|---|---|
| `index.html` | разметка |
| `src/app.ts` | основная логика (постепенно разбивается на модули) |
| `src/products.ts`, `src/data/products.json` | база товаров и поставляемый каталог |
| `src/cards.ts`, `src/cards-io.ts` | дисконтные карты, импорт/экспорт Catima |
| `src/associations.ts` | «С этим часто берут» |
| `src/price-hints.ts`, `src/ai-prices.ts` | оценка цен и ИИ-раскладка по отделам |
| `src/backup.ts` | зеркало, автокопии, восстановление |
| `src/sync.ts`, `firestore.rules` | семейный доступ: синхронизация Firestore, приглашения, правила доступа |
| `src/journal.ts` | журнал семьи и уведомления |
| `src/promos.ts` | акции из газеток (Blix.pl + Gemini) |
| `src/tidy.ts` | «Навести порядок»: названия и цены |
| `src/updater.ts`, `ApkUpdaterPlugin.java` | обновление из GitHub Releases |
| `src/swipe.ts` | свайпы между разделами и эффекты |
| `src/native.ts` | мост Capacitor: файлы, «Поделиться», кнопка «Назад», ключ Gemini |
| `android/` | Android-проект Capacitor |

Технологии: Vite, TypeScript, Tailwind CSS, Capacitor 7, Leaflet, Firebase (необязательная облачная синхронизация), bwip-js и ZXing (штрихкоды), JSZip.
